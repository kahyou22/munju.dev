글을 쓸 때 쓸 수 있는 컴포넌트를 모아둔 견본 글이다. 일부 공개 글이라 목록에는 없고 링크로만 들어올 수 있다. 모든 컴포넌트는 import 없이 바로 쓸 수 있다.

## Callout

팁, 메모, 주의를 상자로 강조한다. `title`을 생략하면 종류 이름이 라벨이 된다.

<Callout type="note">
  메모 상자. 본문 흐름과 조금 떨어진 이야기를 적을 때 쓴다.
</Callout>

<Callout type="tip" title="이렇게 하면 편하다">
  팁 상자. **굵은 글씨**나 `코드`, [링크](https://docs.astro.build)도 그대로 쓸 수 있다.
</Callout>

<Callout type="warn">
  주의 상자. 실수하기 쉬운 부분을 알려줄 때 쓴다.
</Callout>

```mdx
<Callout type="tip" title="이렇게 하면 편하다">
  팁 상자. 내용에 마크다운을 그대로 쓸 수 있다.
</Callout>
```

## Kbd

키보드 키를 손으로 그린 모양으로 보여준다. 복사는 <Kbd>Ctrl</Kbd> + <Kbd>C</Kbd>, 붙여넣기는 <Kbd>Ctrl</Kbd> + <Kbd>V</Kbd>. 방향키는 <Kbd>←</Kbd> <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>→</Kbd>, 그리고 <Kbd>Esc</Kbd>. 같은 글자의 키는 같은 모양이다.

```mdx
복사는 <Kbd>Ctrl</Kbd> + <Kbd>C</Kbd>
```

## Mark

형광펜으로 칠한 듯이 강조한다. 스크롤해서 화면에 들어오면 <Mark>왼쪽부터 쓱 칠해진다</Mark>. 문장이 길어서 <Mark>줄이 바뀌어도 줄마다 따로 칠해지기 때문에 자연스럽게 이어진다</Mark>. 칠하는 모양은 <Mark>세 가지</Mark> 중 하나가 글자에 따라 정해진다.

```mdx
화면에 들어오면 <Mark>왼쪽부터 쓱 칠해진다</Mark>.
```

## Aside

<Aside>이렇게 옆에 적힌다. 화면이 좁으면 본문 사이에 들어간다.</Aside>

여백에 손글씨로 적는 메모다. 메모를 달고 싶은 문단 바로 앞에 두면, 넓은 화면에서는 그 문단 옆 여백에 비스듬히 적힌다. 본문 폭은 그대로라서 읽는 흐름을 방해하지 않는다.

<Aside>메모마다 기울기가 조금씩 다르다.</Aside>

좁은 화면에서는 여백이 없으니 문단 사이에 들어가고, 왼쪽에 손으로 그은 괄호 선이 붙는다.

```mdx
<Aside>이렇게 옆에 적힌다.</Aside>

메모를 달고 싶은 문단.
```

## Figure

글에 사진을 넣는 액자다. 사진 위에 살짝 어긋난 흰 선을 두 번 긋고, 바깥에 포인트 색 스케치 선을 하나 더 둔다. 캡션은 손글씨로 붙는다. 사진은 글 폴더에 두고 import한다.

## Diagram

손으로 그린 듯한 다이어그램이다. 빌드할 때 그림으로 만들어져서 브라우저로 가는 JS가 없다. 스크롤해서 화면에 들어오면 선이 스스로 그려지고, 상자에 마우스를 올리면 그 상자가 꿈틀거리면서 연결된 화살표가 강조된다.

단순한 흐름은 `flow` 하나로 그린다.

<Diagram flow={["글 쓰기", "빌드", "배포"]} caption="flow로 그린 단순한 흐름" />

```mdx
<Diagram flow={["글 쓰기", "빌드", "배포"]} />
```

갈라지거나 합쳐지는 흐름은 상자(`nodes`)와 연결선(`edges`)을 적는다. 상자는 칸(`col`, `row`)에 놓이고, `tone`으로 색을, `shape`로 모양을 바꾼다. 줄바꿈은 `\n`.

<Diagram
  nodes={[
    { id: "a", label: "기본 상자", col: 0, row: 0 },
    { id: "b", label: "accent", col: 1, row: 0, tone: "accent" },
    { id: "c", label: "highlight", col: 2, row: 0, tone: "highlight" },
    { id: "d", label: "tip\n두 줄도 된다", col: 1, row: 1, tone: "tip", shape: "pill" },
    { id: "e", label: "muted", col: 2, row: 1, tone: "muted" },
  ]}
  edges={[
    { from: "a", to: "b", label: "연결" },
    { from: "b", to: "c" },
    { from: "b", to: "d", label: "아래로" },
    { from: "d", to: "e", label: "점선", dashed: true },
  ]}
  caption="상자 색과 모양, 연결선 라벨과 점선"
/>

```mdx
<Diagram
  nodes={[
    { id: "a", label: "기본 상자", col: 0, row: 0 },
    { id: "b", label: "accent", col: 1, row: 0, tone: "accent" },
    { id: "d", label: "tip\n두 줄도 된다", col: 1, row: 1, tone: "tip", shape: "pill" },
  ]}
  edges={[
    { from: "a", to: "b", label: "연결" },
    { from: "b", to: "d", label: "점선", dashed: true },
  ]}
  caption="캡션"
/>
```

  return `안녕, ${name}!`;
}
