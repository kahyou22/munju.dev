글을 쓸 때 쓸 수 있는 컴포넌트를 모아둔 견본 글이다. 일부 공개 글이라 목록에는 없고 링크로만 들어올 수 있다. 모든 컴포넌트는 import 없이 바로 쓸 수 있다.

{/* more */}

## Callout

팁, 메모, 주의를 상자로 강조한다. `title`을 생략하면 종류 이름이 라벨이 된다.

<Callout type="note">
  메모 상자. 본문 흐름과 조금 떨어진 이야기를 적을 때 쓴다.
</Callout>

<Callout type="tip" title="이렇게 하면 편하다">
  팁 상자. **굵은 글씨**나 `코드`, [링크](https://docs.astro.build)도 그대로 쓸 수 있다.
</Callout>

<Callout type="warn">
  주의 상자. 실수하기 쉬운 부분을 알려줄 때 쓴다.
</Callout>

```mdx
<Callout type="tip" title="이렇게 하면 편하다">
  팁 상자. 내용에 마크다운을 그대로 쓸 수 있다.
</Callout>
```

## Kbd

키보드 키를 손으로 그린 모양으로 보여준다. 복사는 <Kbd>Ctrl</Kbd> + <Kbd>C</Kbd>, 붙여넣기는 <Kbd>Ctrl</Kbd> + <Kbd>V</Kbd>. 방향키는 <Kbd>←</Kbd> <Kbd>↑</Kbd> <Kbd>↓</Kbd> <Kbd>→</Kbd>, 그리고 <Kbd>Esc</Kbd>. 같은 글자의 키는 같은 모양이다.

```mdx
복사는 <Kbd>Ctrl</Kbd> + <Kbd>C</Kbd>
```

## 코드 블록

언어 뒤에 `title="파일명"`을 쓰면 코드 위에 파일명이 붙는다. 오른쪽 위의 복사 버튼은 모든 코드 블록에 붙는다.

```ts title="src/lib/greet.ts"
export function greet(name: string) {
  return `안녕, ${name}!`;
}
```
